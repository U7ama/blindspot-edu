# Small student pilot

Recruit 5–8 consenting classmates through the user or brother. No messages are sent automatically. Use one permission-approved course recording and keep classroom audio private unless public playback permission is separately documented.

1. Have a knowledgeable course participant check each prerequisite, worked example, question and answer.
2. Use three small fixtures: a genuinely under-explained prerequisite, a concept explained later, and a fully explained lecture with no expected gap. Include a second subject to expose hard-coded assumptions.
3. Record an independent pre-check, then use the lesson, then a different comparable application question. Avoid reuse of the same question as a learning-gain metric.
4. Record completion time, hints, source-link usefulness, failures/abandonment and optional next-day retention.
5. Export pseudonymous attempt results with `python -m scripts.admin pilot-export results.csv`. This is raw interaction evidence, not a causal learning-effect estimate; separate retries from first attempts.
6. Report actual participant count, paired scores and mixed outcomes. Do not claim broad effectiveness or underserved status without evidence.
